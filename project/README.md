# DevOps 프로젝트 과제

## 프로젝트 소개
Guestbook 방명록 애플리케이션을 활용하여
Docker, Kubernetes, GitHub Actions 기반의
자동화 및 배포 과정을 실습하였다.

## 주요 실습 내용
- Guestbook 애플리케이션 수정
- Docker 이미지 빌드 및 GHCR 업로드
- Kubernetes 애플리케이션 배포
- Redis 연결 오류 확인 및 복구
- Probe 설정 오류 확인 및 복구
- GitHub Actions CI/CD 자동화
- Issue, Pull Request, Merge를 통한 협업

## 실습 결과
오류 발생 원인을 확인하고 복구하였으며,
수정된 애플리케이션의 정상 배포를 확인하였다.
