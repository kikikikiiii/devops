# DevOps 4주차 - 네트워크 실습

## 1. 학습 목표
- 네트워크의 기본 개념과 동작 원리 이해
- IP 주소와 포트의 개념 학습
- 리눅스 네트워크 명령어 사용
- 네트워크 연결 상태 확인 및 문제 해결

## 2. 주요 개념

### IP 주소
네트워크에서 장치를 구분하기 위해 사용하는 주소이다.

### 포트(Port)
하나의 컴퓨터에서 실행되는 여러 네트워크 서비스를 구분하는 번호이다.

### TCP와 UDP
- TCP: 연결 지향 방식으로 신뢰성 있는 데이터 전송
- UDP: 비연결형 방식으로 빠른 데이터 전송

### 방화벽(Firewall)
네트워크 트래픽을 규칙에 따라 허용하거나 차단하는 보안 기능이다.

## 3. 주요 명령어

```bash
ip addr
ip route
ping 8.8.8.8
ss -tuln
curl https://example.com
sudo ufw status
```

- `ip addr`: 네트워크 인터페이스 및 IP 주소 확인
- `ip route`: 라우팅 테이블 확인
- `ping`: 네트워크 연결 확인
- `ss -tuln`: TCP/UDP 수신 포트 확인
- `curl`: HTTP 요청 및 응답 확인
- `sudo ufw status`: 방화벽 상태 확인

## 4. 실습 내용
1. 리눅스 네트워크 환경 확인
2. IP 주소 및 라우팅 정보 확인
3. ping을 이용한 네트워크 연결 테스트
4. 포트 및 네트워크 서비스 상태 확인
5. 방화벽 상태 확인

## 5. 실습 결과
네트워크 관련 명령어를 사용하여 IP 주소, 연결 상태, 포트 및 방화벽 설정을 확인하는 방법을 학습하였다.

## 6. 느낀 점
이번 실습을 통해 리눅스에서 네트워크 상태를 확인하는 방법과 네트워크 문제를 점검하는 기본적인 과정을 이해할 수 있었다.
