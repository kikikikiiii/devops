# DevOps 3주차 - 셸 스크립팅

## 1. 학습 목표
- 리눅스 셸과 셸 스크립트의 개념 이해
- 기본 셸 명령어 사용
- 셸 스크립트 작성 및 실행 방법 학습
- 반복 작업을 스크립트로 자동화하는 방법 이해

## 2. 주요 명령어

```bash
pwd
ls
cd
chmod +x start.sh
./start.sh
```

- `pwd`: 현재 작업 디렉터리 확인
- `ls`: 디렉터리 내 파일 목록 확인
- `cd`: 작업 디렉터리 이동
- `chmod +x`: 스크립트 실행 권한 부여
- `./start.sh`: 현재 디렉터리의 스크립트 실행

## 3. 실습 내용
GitHub의 `week03/qwen-web` 폴더에서 `start.sh` 파일을 관리하였다.

셸 스크립트는 여러 명령어를 파일에 작성하여 반복 작업을 자동화하는 데 활용할 수 있다.

## 4. 실습 결과
- `start.sh` 파일을 GitHub에 업로드하였다.
- Git을 이용해 셸 스크립트 파일의 변경 이력을 관리하였다.

## 5. 배운 점
셸 스크립트를 활용하면 반복적으로 입력해야 하는 명령어를 하나의 파일로 관리할 수 있다. 또한 GitHub를 통해 스크립트의 변경 사항을 기록하고 공유할 수 있다는 점을 배웠다.
