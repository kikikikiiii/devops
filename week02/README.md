# DevOps 2주차 - Git 및 GitHub 기초

## 1. 학습 내용
- Git을 이용한 파일 버전 관리
- GitHub 원격 리포지터리 생성 및 연결
- 파일 변경 사항을 커밋하고 GitHub에 업로드

## 2. 주요 명령어

```bash
git status
git add .
git commit -m "first commit"
git push origin main
```

- `git status`: 파일 변경 상태 확인
- `git add .`: 변경 파일을 스테이징 영역에 추가
- `git commit`: 변경 사항을 로컬 저장소에 기록
- `git push`: 로컬 커밋을 원격 저장소에 업로드

## 3. 실습 내용
GitHub에 devops 리포지터리를 생성하고 week02 폴더에 실습 파일을 업로드하였다.

## 4. 배운 점
Git은 파일의 변경 이력을 관리하는 도구이며, GitHub를 활용하면 작업한 파일을 원격 저장소에 보관하고 공유할 수 있다는 것을 알게 되었다.
